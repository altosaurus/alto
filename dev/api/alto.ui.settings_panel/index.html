alto.ui.settings_panel

The settings panels that slide in beside an exercise, and the small widgets they are built from.

Each exercise with settings has a panel: a menu of rows (Clefs, Range, Key signatures …) that each lead to a page. Edits are live: they change the shared settings object, are saved, and a changed signal tells the exercise to ask a new question. This module also loads and saves each exercise’s settings.

Examples

>>> _key_label(2)
'D  ·  2♯'
>>> row = _Row("Clefs")
>>> row.title.text()
'<b>Clefs</b>'

load_note_names

def load_note_names() -> None

Load the saved note identification settings into the shared settings object.

Settings saved by an older version, which had a switch between the grand staff and single clefs, are converted. Anything in the saved data that is not valid is ignored.

Examples

>>> cfg_ = settings.note_names
>>> cfg_.clefs = {"alto"}
>>> save_note_names()
>>> cfg_.clefs = {"treble"}
>>> load_note_names()
>>> cfg_.clefs
{'alto'}
>>> cfg_.clefs = {"treble", "bass"}
>>> save_note_names()

The settings of a key signature exercise: a menu with a page for each group of settings.

The same panel serves key signature identification, key signature construction and scale construction, each saving under its own name.

The menu has Clefs, Scales and Key signatures. Scale construction has two key signature choices side by side, one for the staff (Staff keys) and one for the scale itself (Scale keys), and Octave and Steps switches. Edits are live: each changes the settings, saves them and emits changed.

  • boxes (dict of str to QCheckBox): The clef checkboxes.
  • modes (ChoiceChecklist): The scales (major, minor and the modes).
  • key_list (KeyChecklist): The key signatures (of the scales, in scale construction).
  • staff_key_list (KeyChecklist or None): The key signatures that may be drawn on the staff; only scale construction has it.

Examples

>>> panel = KeySignatureSettingsPanel(settings.KeySignatureSettings())
>>> panel.modes_row.value.text()
'2 of 7'

Constructor

Build the panel for a set of settings.

Parameters

  • cfg (KeySignatureSettings): The settings to edit.
