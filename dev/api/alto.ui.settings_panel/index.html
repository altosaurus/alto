alto.ui.settings_panel

The settings panels that slide in beside an exercise, and the small widgets they are built from.

Each exercise with settings has a panel: a menu of rows (Clefs, Range, Key signatures …) that each lead to a page. Edits are live: they change the shared settings object, are saved, and a changed signal tells the exercise to ask a new question. This module also loads and saves each exercise’s settings.

Examples

>>> _key_label(2)
'D  ·  2♯'
>>> row = _Row("Clefs")
>>> row.title.text()
'<b>Clefs</b>'

load_note_names

def load_note_names() -> None

Load the saved note identification settings into the shared settings object.

Settings saved by an older version, which had a switch between the grand staff and single clefs, are converted. Anything in the saved data that is not valid is ignored.

Examples

>>> cfg_ = settings.note_names
>>> cfg_.clefs = {"alto"}
>>> save_note_names()
>>> cfg_.clefs = {"treble"}
>>> load_note_names()
>>> cfg_.clefs
{'alto'}
>>> cfg_.clefs = {"treble", "bass"}
>>> save_note_names()

KeySignatureSettingsPanel

KeySignatureSettingsPanel(
    cfg: settings.KeySignatureSettings,
    *,

    keys_title: str = 'Key signatures',

)

Bases: ExerciseSettingsPanel

The settings of a key signature exercise: a menu with a page for each group of settings.

The same panel serves key signature identification, key signature construction and both scale exercises, each saving under its own name.

The menu has Clefs, Scales and Key signatures. Both scale exercises have independent staff and scale key choices; construction also has Octave and Steps switches. Edits are live: each changes the settings, saves them and emits changed.

Attributes

  • cfg (KeySignatureSettings): The settings being edited.
  • prefix (str): What the settings are saved under, such as “keySignatures”.
  • stack (SlideStack): The menu and its pages.
  • boxes (dict of str to QCheckBox): The clef checkboxes.
  • modes (ChoiceChecklist): The scales (major, minor and the modes).

The settings of the circle of fifths exercise: which kinds of question to ask, and the colors of the circle.

The menu has two rows. Questions opens a page of switches. Colors opens a page of color schemes to choose from, with a button to make one of your own, which opens an editor. Edits are live: each changes the settings and saves them. A new kind of question emits changed, and a new color scheme emits restyled, which keeps the question.

  • stack (SlideStack): The menu and its pages: the menu, the questions, the color schemes and the editor of a scheme.
  • questions_row (_Row): The menu row for the questions.
  • colors_row (_Row): The menu row for the colors; its value is the name of the chosen scheme.
  • questions (ChoiceChecklist): The kinds of question: relative major, relative minor and Roman numerals.
  • schemes (SchemePage): The color schemes.
  • editor (SchemeEditor): The editor of a scheme of your own.

Examples

('3 of 3', 'Cyan to indigo')
