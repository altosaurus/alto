The exercises: note names, intervals, key signatures, scales, chords,
arpeggios, keyboard keys and note construction.

## Classes

- [`NoteNames`](class-notenames/) — Name the note shown on a staff.
- [`IntervalNames`](class-intervalnames/) — Name the interval between two written notes.
- [`IntervalConstruction`](class-intervalconstruction/) — Place a second written note at the requested interval from a given note.
- [`KeyboardIntervals`](class-keyboardintervals/) — Identify the ascending interval between two highlighted piano keys.
- [`KeySignatures`](class-keysignatures/) — Read a key signature drawn on a staff and name the key it belongs to.
- [`KeySignatureConstruction`](class-keysignatureconstruction/) — Build the key signature of a named key on a blank staff, with the fork.
- [`OrderOfKeys`](class-orderofkeys/) — Write the accidentals of a named key signature in order.
- [`ScaleIdentification`](class-scaleidentification/) — Identify the tonic and type of a scale drawn on a staff.
- [`ScaleConstruction`](class-scaleconstruction/) — Place the notes of a named scale on a blank staff, one after another.
- [`CircleOfFifths`](class-circleoffifths/) — Questions on the circle of fifths: a relative major, a relative minor, or the Roman numeral of a chord.
- [`ChordQualities`](class-chordqualities/) — Identify the quality of a triad or seventh chord in root position.
- [`ArpeggioNames`](class-arpeggionames/) — Name the type and the inversion of a broken chord.
- [`KeyboardNotes`](class-keyboardnotes/) — Name the highlighted key on a piano keyboard.
- [`NoteConstruction`](class-noteconstruction/) — Place a named note on the staff.
- [`ClefBasics`](class-clefbasics/) — Put a named clef on a blank staff: choose the G, C or F symbol and put it on the line that makes the clef asked for.
- [`NotationIdentification`](class-notationidentification/) — Identify the highlighted part of a written phrase.
- [`BeatIdentification`](class-beatidentification/) — Identify the time signature or classify the meter of a rhythm.
- [`BeatConstruction`](class-beatconstruction/) — Mark where the main beats begin in two written measures.
- [`RythmicEquations`](class-rythmicequations/) — Complete arithmetic equations with written note values.

## Functions

- [`beat_meter`](function-beat_meter/) — Look up the written time signature for either kind of answer.
- [`beat_positions`](function-beat_positions/) — Get the main beat starts in two measures, measured in eighth notes.

`@register`, so importing this module is what adds

Construction']
